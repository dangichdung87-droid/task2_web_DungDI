# Management System Website - Task 2

A modern, responsive frontend management system and course portal built with HTML5, CSS3, and JavaScript.

🌐 **Live Demo:** [https://dangichdung87-droid.github.io/task2_web_DungDI/](https://dangichdung87-droid.github.io/task2_web_DungDI/)  
📦 **Repository:** [https://github.com/dangichdung87-droid/task2_web_DungDI](https://github.com/dangichdung87-droid/task2_web_DungDI)

---

## 🌟 Key Features

- **Interactive Hero Carousel:** Automatic 5-second slide transitions with manual previous/next navigation and indicator dots. Pauses on hover.
- **Our Goal & Features Section:** Clean 2-column layout showcasing mission and 4 core value cards (Easy to Use, Secure, Efficient, Better Productivity).
- **Course Portal & Interactive Modal (`courses.html`):** 2x2 grid displaying development courses (HTML, CSS, Bootstrap, JavaScript). Clicking "Learn More" opens an interactive modal with full syllabus details.
- **Modern Login Experience (`login.html`):** Form interface with show/hide password toggle, simulated authentication, and redirect to the courses page.
- **Fully Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices using CSS Flexbox and Grid.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/dangichdung87-droid/task2_web_DungDI.git
   ```
2. Open the project folder and double-click `index.html` to run in any modern web browser (Chrome, Edge, Firefox, Safari).
3. (Optional) Use a local development server like VS Code Live Server:
   - Right-click `index.html` -> **Open with Live Server**.

---

## 🌐 GitHub Pages Deployment

1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. The live site will be accessible at:  
   👉 **`https://dangichdung87-droid.github.io/task2_web_DungDI/`**
