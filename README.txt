TASK 2 - MANAGEMENT SYSTEM WEBSITE

Files:
- index.html: Home page with 3-slide carousel, goal section, feature cards and CTA.
- login.html: Frontend-only login demo.
- courses.html: Four course cards and course details modal.
- css/style.css: Shared styles and responsive layout.
- js/script.js: Carousel, mobile menu, login demo, and course modal.

HOW TO RUN LOCALLY
1. Extract the ZIP file.
2. Open the Task2_Management_System folder.
3. Double-click index.html to open it in your browser.
4. Internet is needed for the Unsplash photos because the images are loaded from their URLs.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository (for example, Task2-Management-System).
2. Upload all files and folders inside this project folder to the repository root.
3. On GitHub, open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. Open the live URL shown in Settings -> Pages and test every page.

IMPORTANT
- This is a frontend-only assignment project. It does not use a database or backend.
- Login success is simulated in the browser. It does not verify a real account or store passwords.
- The images are loaded from the Unsplash URLs provided by you.
